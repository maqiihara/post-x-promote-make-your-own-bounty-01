An X post that quotes make.fun's make-your-own-bounty post and asks one question: what bounty would you make? The post itself is the entry — the program here, `main.ts`, only carries the post's address from `POST.json` into `/output` for the grader to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
